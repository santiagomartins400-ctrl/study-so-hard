Carrega o manual ou os teus apontamentos e faz perguntas. A IA responde apenas com base no que carregaste, e podes gerar cartões de revisão.

Usar no navegador

Sem instalar nada. Funciona no computador e no telemóvel.

Abrir a aplicação

Instalar no Windows

Instalador para Windows 10 e 11. Abre-se como uma aplicação normal.

Descarregar instalador v1.1.1

O instalador é descarregado do GitHub. Como não tem assinatura digital, o Windows pode mostrar um aviso: escolhe «Mais informações» e depois «Executar mesmo assim».

Como instalar no Windows

  • Abre a página de versões e descarrega o ficheiro Study-So-Hard-Setup (.exe).
  • Executa o instalador e segue os passos. Pode escolher a pasta de instalação.
  • Abre o Study So Hard pelo atalho no ambiente de trabalho ou no menu Iniciar.

Privacidade

Os ficheiros e as conversas ficam guardados no teu navegador ou computador. O texto das perguntas e partes do manual são enviados à OpenAI para gerar as respostas, com a tua chave de API.
